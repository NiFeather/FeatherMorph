# Gameplay
## Disguise
There are several ways to unlock a disguise:
  - To kill a mob or a player
  - Send an exchange request to someone
  - Use Magic Bottle to collect disguise from friendly mobs and players

Once unlocked, you will see it in your disguise list, you can check it by either using the command or opening the disguise selection GUI.

Assuming you are using the default controls, you can open a selection GUI by:
  - *Sneak + RMB* whil holding Disguise Tool, which will introduce later.
  - Execute the `/morph` command
  - Press *N* if you are using the client mod.

To undisguise yourself:
  - *Sneak + LMB* a Disguise Tool
  - Use the `/unmorph` command
  - Press *Down Arrow (⬇️)* if you are using the client mod.

### Disguise Action (Animation)
Some disguise have or more animations, you can open the animation selection GUI by:
  - *LMB* while holding Disguise Tool without sneaking
  - Press *G* if you are using the client mod. (The keybind may conflict with *Quick Actions*, you might want to check controls first)
  - Use the `/play-action` command

Once opened, click on an action to play. *Currently, you need to install a compatible client mod to see the current animation playing for your disguise.*

## Disguise tool
Formly known as *Skill Item*.

***By default, the disguise tool can be crafted using feather and redstone.*** The recipe can be configured through the config `recipes.yml`

*Additionally, you can make an item a disguise tool by executing `/fm make_disguise_tool` command while holding it on your main hand.*

Assuming you are using the default controls, the disguise tool can be used to activate these functions:
| Method | Function |
| --- | --- |
| Sneak + Right Click | Open disguise selection / Quick disguise |
| Sneak + Left Click | Undisguise |

When disguising:
| Method | Function |
| --- | --- |
| Right Click | Activate skill |
| Left Click | Open disguise action selection |
